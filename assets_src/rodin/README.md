# Rodin (Hyper3D) models

Characters and props generated by Lasha with Hyper3D Rodin (Creator plan) for this game, from his own prompts.
Licence notes: `docs/ASSET_LICENSES.md`.

| Game file | Rodin prompt |
|---|---|
| `public/models/caveman_slingshot.glb` | Prehistoric man using a slingshot |
| `public/models/stone_hut.glb` | A small stone hut structure |

Rodin exports are ~500k triangles with 2K textures split into many UV islands, which blocks
normal simplification. `bake.mjs` samples the base-colour texture into vertex colours, welds the
seams, simplifies to a triangle budget (meshoptimizer) and writes a small GLB (~450 KB):

```
npm i @gltf-transform/core@4.1.1 @gltf-transform/extensions@4.1.1 meshoptimizer@0.22.0 sharp@0.33.5
node bake.mjs base_basic_pbr.glb caveman_club.glb 14000
node bake.mjs base_basic_pbr.glb caveman_slingshot.glb 14000 largest   # drop stray fragments
```

The models have no skeleton; `src/render/age1/autorig.ts` rigs them on load (legs + torso)
and animates them procedurally.

## Rigged characters (2026-10-10 batch)

The 2026-10-10 exports (`raw/2026-10-10/`, identities in its README) are T/A-pose PBR meshes. The raw
`.glb` files stay local (ignored by git); only processed copies go to `public/models/`. Two of them
are rigged and animated in headless Blender by `rig_caveman.py`:

```
blender -b --factory-startup -P assets_src/rodin/rig_caveman.py -- assets_src/rodin/raw/2026-10-10/rodin_a.glb public/models/clubman.glb club
blender -b --factory-startup -P assets_src/rodin/rig_caveman.py -- assets_src/rodin/raw/2026-10-10/rodin_g.glb public/models/dino_rider.glb rider
```

The script welds and decimates the mesh to ~15k tris, scales it to 1.8 m, shrinks the textures to
1024 px, builds a 17-bone skeleton from the mesh's landmarks, skins it with Blender's automatic
weights (vertices bone-heat leaves unweighted go to the nearest bone), adds a `TeamColor` belt and
an original prop (club or spear) on the right hand bone, keys the clips and exports facing +X.

| Game file | Source | Clips |
|---|---|---|
| `public/models/clubman.glb` | `rodin_a` (caveman, T-pose) + club | idle 2 s, walk 0.6 s, attack 0.7 s (club lands ~0.27 s), death 1.2 s |
| `public/models/dino_rider.glb` | `rodin_g` (helmeted caveman, A-pose) + spear | idle (seated) 2 s, attack 0.8 s (spear thrust), death 1 s; seated on the procedural dinosaur by `src/render/age1/dino.ts` |
